# 🎬 IMDB-Clone

A modern, feature-rich IMDb-inspired web application for browsing movies and TV shows, built with **React**, **TypeScript**, and **Vite**.

🔗 **Live Demo:** [imdb-frontend-lovat.vercel.app](https://imdb-frontend-lovat.vercel.app)  
🔗 **GitHub Repository:** [Reallyishan009/IMDB-Clone](https://github.com/Reallyishan009/IMDB-Clone)

---

## 📌 Features

- 🔍 **Search Movies & TV Shows** – Real-time search using the TMDB API.
- 📝 **Detailed Info** – View ratings, overviews, trailers, casts, and crew.
- 📌 **Watchlist** – Add or remove titles from your personal watchlist.
- 💾 **Local Storage Persistence** – Keep watchlists even after refreshing.
- 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile.
- ⚡ **Fast Development** – Hot Module Replacement (HMR) using Vite.
- 🎨 **Modern UI** – Styled with Shadcn UI components + custom CSS.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite
- **UI:** Shadcn UI, TailwindCSS
- **State Management:** Redux Toolkit
- **API:** [TMDB API](https://www.themoviedb.org/documentation/api)
- **Deployment:** Vercel
